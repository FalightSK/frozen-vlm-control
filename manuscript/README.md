# frozen-vlm-control: manuscript

`main.tex` is the current IEEE conference paper; `main.pdf` is its rendered output. The title is fixed. The paper evaluates frozen-feature usefulness through newly trained, matched action-head architectures within each benchmark. Three independent seeds are tested at ALOHA epoch 250 and LIBERO epoch 120. See [results](../docs/RESULTS.md) and the [integrity audit](../docs/analysis/provenance/progression_integrity_audit.json).

The current figures are `aloha_progress_timing.pdf`, `libero_goal_comparison_review.pdf`, `aloha_boundary_compact.pdf`, and `training_progression_review.pdf` under `figures/`. The redundant instruction-outcome plot is supporting material, not a current main-paper figure.

Plot generators are in `scripts/analysis/`: `plot_manuscript_aloha_progress_timing.py`, `plot_manuscript_aloha_boundary.py`, `plot_manuscript_wide_figures.py`, and `plot_manuscript_column_figures.py`. The wide and column generators produce alternative layouts and overwrite some common filenames; use the intended layout deliberately. The current loss plot uses the column layout, while the goal plot uses the wide layout. Figure inputs are curated CSVs under `docs/analysis/` and `manuscript/figure_data/`. Generators run analysis only, without training or simulator rollouts.

Compile the existing `main.tex` in place. It has a six-page upper-limit guard; the conference permits 4–6 pages. Keep all included figure assets in the project. Planning notes and LaTeX intermediates are ignored, while source, final PDF, plots, and curated data are eligible for Git. The editor compiler currently encounters a Windows drive-enumeration error; a local Tectonic build has been used to update `main.pdf`. Final submission still requires the conference's PDF eXpress workflow.
